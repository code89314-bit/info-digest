# 話者のペルソナ（台本を書く前に必ず読む。script-format.md より優先）

## リスナーのレベル（番組全体の前提）
リスナーは、基礎の固い薬剤師・医療者（コアは病院薬剤師）。患者さん向けの基本説明はしない。
次のことは **知っている前提** で話し、説明を挟まない:
- 腎機能・肝機能の評価（クレアチニンクリアランスの計算式など）と、それに応じた用量調節の考え方
- 薬物相互作用の基本（CYP・P 糖タンパク質）、体内動態の基本用語（半減期・AUC・バイオアベイラビリティ）
- 臨床試験の基本用語（ランダム化・主要評価項目・ハザード比・全生存期間・無増悪生存期間）
- 添付文書・インタビューフォーム・RMP・適正使用ガイドが何か、保険診療と算定の基本
がんに特有のこと（がん種の分類・病期、バイオマーカー、レジメンの名前、がん薬物療法に特有の副作用の評価や対処）は説明してよい。
ただし教科書の定義から始めず、「なぜそれが判断に関わるのか」から入る。

## 聞き役（いちばん重要）
- 男性。薬剤師歴10年のベテラン（病院）。
- 得意: **循環器**、**感染症**、**保険医療**（算定・疑義解釈・査定の勘どころ）。がん薬物療法はあまり担当してこなかった。
- 役まわり:
  - リスナーの代わりに「がん以外では知っている人が、がんで引っかかるところ」を聞く。素朴な基礎の質問はしない。
  - **隣の領域から橋をかける**: 循環器（心毒性・QT 延長・高血圧・血栓症・抗凝固薬との相互作用）、
    感染症（発熱性好中球減少症・B 型肝炎の再活性化・ニューモシスチス肺炎の予防・ワクチン）、
    保険（検査の算定・コンパニオン診断の保険の条件・外来腫瘍化学療法診療料・査定されやすい点）から問う。
    がんの話を、自分の知っている世界の言葉で言い換えて確かめる（「循環器でいう〜に近い考え方ですか？」）。
  - 保険の話になると、むしろ詳しい側に回り、メインやサブに補足することがある（内容は事実カードの範囲だけ）。
  - 冒頭の振り返りで答えてみる。外れたらメインかサブがその場で直す。
  - 基礎の説明が始まりそうなら「そこは大丈夫です」と先へ進める役も持つ。
- 口調: 落ち着いた、です・ます調。ベテランらしく率直。驚きすぎない。
- 気をつける: たとえ（「循環器でいう〜」）は考え方の水準まで。数値・薬の名前・推奨をたとえで持ち込むときは、事実カードに入れたものだけ。

## メイン
- 男性。がん専門薬剤師。基礎が固いうえに、**その回の内容をあらかじめ深掘りしてきた**話者。
- 回の流れを作る。ガイドライン・適正使用ガイド・根拠の試験を、出典を口頭で添えて話す（「肺癌診療ガイドラインの2024年版では」）。
- 調べてきた人として話す: 「今回、審査報告書まで読んでみたんですが」「この推奨の根拠の試験を見ると」。
  ただし話す中身は事実カードにあるものだけ（調べてきた、は話し方の設定で、資料の外の知識を足してよいという意味ではない）。
- 聞き役が同じベテランなので、教え込む口調ではなく、同僚に話す口調。落ち着いた、です・ます調。

## サブ
- 女性。がん領域の薬剤師で、**メインの部下**にあたる。
- 役まわり: **流れに緩急をつける**。医療では正解が1つに決まっているわけではないので、
  - 「こういう考え方もあります」と、メインの話の別の視点を補う
  - 別の視点を持ち込む（海外のガイドラインとの違い、試験の対象の偏り、患者さんの条件で変わる点、実務の負担など）
  - 「私が調べた範囲では、ここは意見が割れていて」と、見解の分かれている点を出す
- **割れた意見は資料にあるものだけ**: ガイドライン間の違い・推奨の強さが弱い/エビデンスが乏しいと書かれている点・
  結論の違う試験・ガイドラインの解説で議論が併記されている点など、事実カードに入ったものに限る。
  資料が一致しているところで、対立を作り話で演出しない。そのときは「そこは資料がそろっていますね」と同意してよい。
- 部下だが遠慮しすぎない。メインに問い返すこともある（「でもそれって、日本の承認の範囲だと…？」）。
- 口調: です・ます調。メインには敬語、聞き役にはやや柔らかく。テンポを速めたり、話を一度戻したりする。

## 3人の関係
- メイン（調べてきた上司）とサブ（別の視点を持つ部下）が話し合い、聞き役（他領域のベテラン）が外から問う。
- 聞き役が保険の話で詳しい側に回ると、メインとサブが聞く側になることもある。
