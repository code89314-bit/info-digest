# 台本の形（ep<n>-script.md）

読み上げソフトで読ませる前提の台本。**話者は3人に固定**し、行の先頭のラベルで声を割り当てる（話者の入れ替わりを防ぐ）。
1人が教え続けると説明的でくどくなるので、メインとサブが違う立場から話し合い、聞き役が聞いている人の代わりに入る。

## 話者
ラベルは `堀田:` `横井:` `司:` の3つだけ（読み上げソフトはこのラベルで声を割り当てる）。
人物像・呼び方・リスナーのレベル（説明を挟まない前提知識）は **`persona.md`**。
- 堀田（メイン）: 男性のがん専門薬剤師。その回を深掘りしてきた人として、流れを作り、出典を口頭で添えて話す。
- 横井（サブ）: 女性、堀田の部下。別の視点・割れた意見（資料にあるものだけ）で緩急をつける。
- 司（聞き役）: 薬剤師歴10年、循環器・感染症・保険に詳しく、がんは手薄。あくまで聞き役。隣の領域の切り口から問い、確かめるだけで、自分から説明しない・割り込まない。一人称は極力省く。
以下、メイン＝堀田、サブ＝横井、聞き役＝司。

### 掛け合いのきまり
- 話す量の目安: 堀田 45〜50%、横井 25〜30%、司 20〜25%（リスナーは堀田の説明を聞きに来ている）。同じ人が3つ以上続けて話さない。
- 本編ごとに、メインとサブが話し合う場面を1回は作る（違う角度・補い合い・「そこは資料では確認できないですね」と線を引く）。
  意見の対立を作り話で演出しない。違いは「資料のどこを見るか」「誰の視点か」の違いとして出す。
- 聞き役が答えてみて少し外れたときは、その場で正しい説明に直す（間違ったまま次へ進まない）。
- 1行に1人だけ。ラベルの無い行・4人目・ナレーションは作らない（見出しは `## ` で書き、読ませない）。
- 1つのせりふは長くても200字まで。長い説明は、ほかの2人の相づち・質問で区切る。
- 呼び方は persona.md の表のとおり（横井→「堀田君」、堀田→「よこぽん」、司→「よこちゃん」、2人→「司さん」）。
  話の向きを変えるときだけ使い、毎回の発言には入れない。

## 全体の組み立て（約6,000字 ≒ 20分。日本語の読み上げは1分に約300字）
```markdown
---
series: 連載：{title}
episode: 3
title: ガイドラインのいま
type: structure
week_id: 20261122-egfr-nsclc
chars: 6100
sources: 12
---
## オープニング（約150字。司のタイトルコールで始める。名乗り・自己紹介はしない）
## 前回の振り返り（約300字。第2回から。メインが問い→聞き役が答えてみる→サブがひとこと補足）
## 本編1 …（約1,500字）
## 本編2 …
## 本編3 …
## 今日のポイント（3つ。聞き役がまとめ、メインとサブが1つずつ補う）
## 次回予告（約100字）
## おことわり（司が読み、続けて「連載『…』、第n回でした。次回もよろしくお願いします」で締める。定型: 「この番組は、添付文書・ガイドラインなどの資料をもとに作成しています。実際の判断は最新の添付文書・ガイドライン原文でご確認ください。」）
```

## 読みがな（読み間違いを防ぐ）
- 読み間違えそうな語は `{表記|よみ}` で書く。よみはひらがな・カタカナ。読み上げのときは「よみ」を読ませ、記事では「表記」を使う。
  - 例: `{EGFR|イージーエフアール}`、`{mg/m²|ミリグラムまいへいほうメートル}`、`{AUC|エーユーシー}`、`{寛解|かんかい}`、
    `{奏効率|そうこうりつ}`、`{PS|ピーエス}`、`{Grade 3|グレードスリー}`、`{2024年版|にせんにじゅうよねんばん}`
- 付ける語: 英字の略語、単位、記号（≧ ％ ／）、薬の一般名・商品名（初めて出るとき）、試験の名前、読みの割れる漢字の医学用語。
- 同じ回の2回目以降も、英字の略語と単位には毎回付ける（読み上げソフトが文脈で読み替えないため）。
- 読みは `style/series_yomi.yaml` にあればそれに合わせる。無ければ足す（迷うものは「要確認」）。
- 数字は読み上げやすく: 「12.5%」→ `{12.5%|じゅうにてんごパーセント}`、「HR 0.46」→ `{HR 0.46|ハザードひ れいてんよんろく}`。

## 演出（人が話している感じを出す。2026-11-20 本人の指示: NotebookLM の音声くらい）
読み上げだけだと無機質になる。NotebookLM の音声のように、抑揚・笑い・タメ・相づち・言いよどみを台本に書く。
- **行頭の演出**: `堀田: （笑いながら）いつものことですね` — 行頭の（ ）は声の作り方の指示で、読ませない。
  例: （笑いながら）（少し考えて）（驚いて）（しみじみと）（楽しそうに）（ゆっくり、強調して）（照れくさそうに）
- **せりふの中の印**: `[笑]` 短い笑い、`[間]` ひと呼吸のタメ。どちらも読ませない（声のソフトが笑い・間にする）。
- **話し言葉**: 「えっと」「あー、なるほど」「うんうん」「そうそう」、言い直し（「これは、いや、正確に言うと」）、
  短い相づちだけの行（「ええ」「へえ」「はい」）を入れる。相づちだけの行は、話す人の連続の数に入れない。
- **量の目安（NotebookLM くらい）**: 笑い（[笑] か（笑いながら））を1回に8〜12回、相づち・言いよどみを本編ごとに数回。
  笑いどころ: 堀田が時間を押す場面、司の素朴な問い、堀田の熱が入りすぎた場面、横井の軽いつっこみ。
  専門の内容（数字・推奨・薬の名前）を言う行には笑いを入れない（聞き取りにくくなる）。
- **お約束の掛け合い**（persona.md）: 堀田が長いカタカナの薬の名前で詰まる → 司のつっこみ・悪乗り → 横井は乗らない →
  正しい名前を言い直す。始めのほうで詰まった名前は、終わりのほうでもう一度詰まる（回収）。詰まった名前は plan.md に記録する。
- 演出は事実ではないので事実カードは要らない。ただし演出で内容を変えない（笑いで推奨の強さをぼかすなど）。

## 歴史的な変遷を必ず入れる（全回。2026-11-20 本人の指示）
- どの回も、いまの推奨・使い方を「過去からどう変わってきたか」とつなげて話す（例: 以前の版の推奨 → 根拠の試験 → いまの版）。
  つながりがあると記憶に残りやすく、ストーリーが生まれて面白くなる。
- 年・版・承認の年月は事実カードを通す。前の回で出た年表と矛盾させない（前の回の事実カードを読む）。
- 本編ごとに「以前は〜だった」「〜年の〜試験で変わった」を1回は入れる。

## 仕掛けの引き出し（2026-11-22 本人の方針: 毎回は入れない。決まった条件がそろった「ここぞ」の時だけ）
毎回同じ仕掛けが入ると、型が見えて面白くなくなる。下の引き出しから、**その回の中身が条件に合うものだけ**を選ぶ。
条件に合うものが無ければ、仕掛けなしでよい（普通のタイトルコール → 本題、普通の次回予告）。

選び方の決まり:
- **数は決めない**（2026-11-22 本人）。条件がそろっていれば、たくさん入ったノリの良い回があってよいし、静かに説明を聞かせる回があってもよい。
  回ごとに温度差があるほうが、型が見えなくて面白い。ただし条件がそろっていないのに入れない（無理に入れると寒い）。
- **同じ仕掛けを続けて2回は使わない**のが基本（第1回で冒頭の謎を使ったら、第2回は使わない）。
- 例外は「名前で詰まる」: 条件（本当に長い名前が出る）に合う回なら使ってよい。ただし同じ週で同じ名前は、回収（その回の終わり）以外で繰り返さない。
- 使った仕掛けと、その理由（どの条件に合ったか）を plan.md の各回の「使った仕掛け」に書く。次の回を書く前に読む。
- 仕掛けの中身（謎・クイズの答え・言い換え・昔の記載）は、すべて事実カードにあるもの。

| 仕掛け | ここぞの条件（これがそろった時だけ） | やり方 |
|---|---|---|
| 冒頭の謎 | その回に、はっきりした**逆転・意外な順序**がある（理由より薬が先、新しい薬のほうが推奨が弱い、期待された試験が負けた など） | タイトルコールのあと、堀田が山場を謎として投げ、答えは後半。横井「その顔は、答えをまだ言う気がないですね」。本編で「冒頭の謎の答えが、これです」と回収 |
| 司へのクイズ | **直感と大きくずれる数字**がある（がん以外のベテランなら外しそうな数字。例: 日本人の腺がんの約半分が EGFR 陽性） | 堀田「司さんにクイズです」→ 司が理由のある外し方をする → 横井がさらっと正解 → 司が驚く。1回に1〜2問 |
| 次回予告の問い | 次の回の資料に、**一言で問える問いと、その答え**がある | 「次回は〜です」に問いを1つ添える。横井「その答えは、次回です」。次の回で必ず答える（plan.md に書く） |
| 名前で詰まる | **本当に長い名前**が出る: 2語の一般名（ボルヒアルロニダーゼ アルファ、エンホルツマブ ベドチン、トラスツズマブ デルクステカン、サシツズマブ ゴビテカン など）か、カタカナ12字以上。オシメルチニブ・アミバンタマブ程度では詰まらない | 堀田が言いよどむ/笑う → 司がつっこみ・悪乗り → 横井は乗らず正しい名前（詳しくは persona.md） |
| 横井の引き戻し | 堀田が、plan.md で**後の回に割り当てた話**に入りかける | 横井「堀田君、それは第4回の話です」→ 堀田「……ですね」→ 司「続きも聞きたいです」 |
| 司の「隣の領域でいうと」 | しくみが循環器・感染症・保険の考え方に**素直に重なる**（耐性 ⇔ 耐性菌、選択性 ⇔ β1選択性、検査の算定 など） | 司が言い換えて「〜みたいな話ですかね？」→ 堀田が「近いです。ただ違うのは〜」と違いも添える。考え方の水準まで |
| 昔の資料を読む | **古い資料の記載が今と食い違う**（例: 2016年の資料では「術後の有効性は確立していない」→ 今は術後に使う） | 堀田が当時の文言をそのまま読み、間をおいて今の推奨と並べる。司「たった〜年で、ですか」 |
| 意見が割れた舞台裏 | ガイドラインの投票が**大きく割れた**（少数側が3割以上）、または委員会の議論が資料にある | 横井「実はこの推奨、投票が割れていて」→ 割れた理由を資料どおりに。堀田は自分の意見を足さない |
| 答え合わせで外す | 前の回に**取り違えやすい点**があった（第2回以降の冒頭の振り返り） | 司が振り返りの問いに答えて半分外す → 横井か堀田がその場で直す |
| 今日のひとこと | その回の芯が**一言で言える**（例: 「EGFR は、薬が先、理由が後」） | 今日のポイントの最後に、堀田か横井が一言でまとめる。最終回で各回のひとことを並べる |

## 第1回の冒頭（週の最初の回だけ）
- オープニングのあとに「全体の前提」を置く: 罹患数・死亡数・5年生存率などの疫学データ（国立がん研究センターのがん統計など、
  資料にあるもの・年を明記）から、これから話すことがどのくらいメジャーな話かを示す。
  がん種全体 → そのうちの対象（例: 非小細胞肺がん → EGFR 遺伝子変異陽性）の順に絞り込む。

## 内容のきまり
- 事実はすべて `ep<n>-facts.md` にあるものだけ。出典を口頭で添える。
- 試験間比較をしない。作り話をしない。個別の患者への判断をしない。
- 同じ週の前の回と矛盾しない（前の回の事実カードを読む）。前の回で話したことは「第2回で見たとおり」と短く触れるだけ。
- 聞き役の問いかけを、本編ごとに1回は入れる（聞いている人も一緒に考えられるように）。
- サブの「こういう説もある」「意見が割れている」も、事実カードの範囲だけ。「現場ではこうしている」という経験談を作らない。
