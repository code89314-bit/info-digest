# 台本の形（ep<n>-script.md）

読み上げソフトで読ませる前提の台本。**話者は3人に固定**し、行の先頭のラベルで声を割り当てる（話者の入れ替わりを防ぐ）。
1人が教え続けると説明的でくどくなるので、メインとサブが違う立場から話し合い、聞き役が聞いている人の代わりに入る。

## 話者
ラベルは `照井:` `しらべ:` `わた:` の3つだけ（読み上げソフトはこのラベルで声を割り当てる）。
人物像・呼び方・リスナーのレベル（説明を挟まない前提知識）は **`persona.md`**。
- 照井（メイン）: 男性のがん専門薬剤師。その回を深掘りしてきた人として、流れを作り、出典を口頭で添えて話す。
- しらべ（サブ）: 女性、照井の部下。別の視点・割れた意見（資料にあるものだけ）で緩急をつける。
- わた（聞き役）: 薬剤師歴10年、循環器・感染症・保険に詳しく、がんは手薄。あくまで聞き役。隣の領域の切り口から問い、確かめるだけで、自分から説明しない・割り込まない。一人称は極力省く。
以下、メイン＝照井、サブ＝しらべ、聞き役＝わた。

### 掛け合いのきまり
- 話す量の目安: 照井 45〜50%、しらべ 25〜30%、わた 20〜25%（リスナーは照井の説明を聞きに来ている）。同じ人が3つ以上続けて話さない。
- 本編ごとに、メインとサブが話し合う場面を1回は作る（違う角度・補い合い・「そこは資料では確認できないですね」と線を引く）。
  意見の対立を作り話で演出しない。違いは「資料のどこを見るか」「誰の視点か」の違いとして出す。
- 聞き役が答えてみて少し外れたときは、その場で正しい説明に直す（間違ったまま次へ進まない）。
- 1行に1人だけ。ラベルの無い行・4人目・ナレーションは作らない（見出しは `## ` で書き、読ませない）。
- 1つのせりふは長くても200字まで。長い説明は、ほかの2人の相づち・質問で区切る。
- 呼び方は persona.md の表のとおり（しらべ→「照井君」、照井→「しらぽん」、わた→「しらっちゃん」、2人→「わたさん」）。
  話の向きを変えるときだけ使い、毎回の発言には入れない。

## 全体の組み立て（約6,000字 ≒ 20分。日本語の読み上げは1分に約300字）
```markdown
---
series: 連載：{title}
episode: 3
title: ガイドラインのいま
type: structure
week_id: 20261122-egfr-nsclc
chars: 6100
sources: 12
---
## オープニング（約150字）
## 前回の振り返り（約300字。第2回から。メインが問い→聞き役が答えてみる→サブがひとこと補足）
## 本編1 …（約1,500字）
## 本編2 …
## 本編3 …
## 今日のポイント（3つ。聞き役がまとめ、メインとサブが1つずつ補う）
## 次回予告（約100字）
## おことわり（定型: 「この番組は、添付文書・ガイドラインなどの資料をもとに作成しています。実際の判断は最新の添付文書・ガイドライン原文でご確認ください。」）
```

## 読みがな（読み間違いを防ぐ）
- 読み間違えそうな語は `{表記|よみ}` で書く。よみはひらがな・カタカナ。読み上げのときは「よみ」を読ませ、記事では「表記」を使う。
  - 例: `{EGFR|イージーエフアール}`、`{mg/m²|ミリグラムまいへいほうメートル}`、`{AUC|エーユーシー}`、`{寛解|かんかい}`、
    `{奏効率|そうこうりつ}`、`{PS|ピーエス}`、`{Grade 3|グレードスリー}`、`{2024年版|にせんにじゅうよねんばん}`
- 付ける語: 英字の略語、単位、記号（≧ ％ ／）、薬の一般名・商品名（初めて出るとき）、試験の名前、読みの割れる漢字の医学用語。
- 同じ回の2回目以降も、英字の略語と単位には毎回付ける（読み上げソフトが文脈で読み替えないため）。
- 読みは `style/series_yomi.yaml` にあればそれに合わせる。無ければ足す（迷うものは「要確認」）。
- 数字は読み上げやすく: 「12.5%」→ `{12.5%|じゅうにてんごパーセント}`、「HR 0.46」→ `{HR 0.46|ハザードひ れいてんよんろく}`。

## 内容のきまり
- 事実はすべて `ep<n>-facts.md` にあるものだけ。出典を口頭で添える。
- 試験間比較をしない。作り話をしない。個別の患者への判断をしない。
- 同じ週の前の回と矛盾しない（前の回の事実カードを読む）。前の回で話したことは「第2回で見たとおり」と短く触れるだけ。
- 聞き役の問いかけを、本編ごとに1回は入れる（聞いている人も一緒に考えられるように）。
- サブの「こういう説もある」「意見が割れている」も、事実カードの範囲だけ。「現場ではこうしている」という経験談を作らない。
