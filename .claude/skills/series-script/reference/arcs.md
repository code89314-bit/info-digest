# 6回の流れ（切り口ごと）と、各回に NotebookLM へ聞くこと

`{title}` は週の題材、`{drugs}` は config の drugs。聞くことは目安で、構成表（plan.md）を作るときに題材に合わせて直す。
どの回も、第2回からは冒頭で前回を「問い→答え」で1分振り返る。最終回はまとめと目次。

---
## structure（構造系）: がん種ごとの治療・レジメン選択・検査ストラテジー
本人の調べる順: 周術期／再発・切除不能 → 1〜3次のレジメン → 選ぶ条件とコンパニオン診断。
資料: 専門ノート（config の notebook。ガイドライン PDF）＋ 週のノートブック（ウェブ調査 deep）＋ 保険は hoken。

| 回 | 題 | 聞くこと |
|---|---|---|
| 1 | 全体像と歴史 | {title} の分類・病期とバイオマーカーは？／薬物療法の歴史の主な節目（年と出来事）は？／いまの診療ガイドラインの名前・版・発行年は？ |
| 2 | 検査ストラテジー | 診断時に調べるバイオマーカーと検査法は？／コンパニオン診断薬と対応する薬は？／遺伝子パネル検査をいつ使うか？／検査の保険の条件・点数は？（hoken） |
| 3 | 周術期 | 術前・術後の薬物療法の推奨（CQ・推奨の強さ・エビデンスの強さ）は？／根拠の試験（名前・デザイン・主な評価項目）は？／前の版から変わった点は？ |
| 4 | 再発・切除不能の1次治療 | 1次治療で推奨されるレジメンと、選ぶ条件は？／根拠の試験は？／患者さんの条件（PS・年齢・臓器機能）で変わる点は？ |
| 5 | 2次以降と実務 | 2次・3次以降の選択肢と根拠は？／耐性のしくみと再検査は？／薬剤師が確認すること（開始基準・減量・相互作用）は？／保険の注意点は？（hoken） |
| 6 | まとめ | 治療アルゴリズム（言葉で説明できる形）／各回のポイント／最新の承認・改訂（新しい順、日付つき）／目次 |

## class（クラス追跡）: 薬のクラスを追う比較・歴史のキュレーション
資料: 各薬の添付文書・インタビューフォーム・審査報告書・適正使用ガイド（drugs ごとに fast の調査）＋ ガイドライン ＋ 総説。
注意: 試験間比較をしない。薬が多いクラスは scope で絞る（例: 肺がんで使うもの）。

| 回 | 題 | 聞くこと |
|---|---|---|
| 1 | 作用機序と誕生 | {title} の標的と作用機序は？／標的が見つかった経緯と最初の薬は？（年） |
| 2 | 系譜と発売順 | {drugs} の日本での承認の年月と適応は？（古い順）／世代の違いは何を改良したか？／それぞれの承認の根拠の試験は？ |
| 3 | 薬どうしの比較 | {drugs} の用法・用量、体内動態（代謝酵素・半減期）、相互作用、食事の影響は？ |
| 4 | 副作用 | クラスに共通の副作用と、薬ごとに特徴的な副作用は？／重大な副作用の早期発見と休薬・減量の基準は？（適正使用ガイド） |
| 5 | 使い分けと実務 | ガイドラインでの使い分け・推奨は？／耐性と次の治療は？／保険の注意点（適応の条件・検査）は？（hoken） |
| 6 | まとめ | 比較表（言葉で説明できる形）／系譜（年表）／最新の承認（新しい順、日付つき）／目次 |

## drug（ドキュメンタリー）: 1つの薬だけを追う
資料: PMDA の審査報告書（開発の経緯の一次資料）・インタビューフォーム・添付文書・主要な試験の論文。
注意: 作り話をしない。審査報告書・インタビューフォームの「開発の経緯」に書かれたことだけで語る。

| 回 | 題 | 聞くこと |
|---|---|---|
| 1 | 発見と開発 | {title} の標的が見つかった経緯と、創薬の経緯は？（インタビューフォームの開発の経緯） |
| 2 | 臨床試験の歩み | 第I相から承認までの主な試験（名前・対象・デザイン・主な評価項目・結果）は？／うまくいかなかった試験は？ |
| 3 | 承認と適応拡大 | 日本と海外での承認・適応追加の年月（古い順）は？／審査で議論になった点は？（審査報告書） |
| 4 | 現場での使い方 | 用法・用量、開始前の確認、重大な副作用と対処、相互作用は？（添付文書・適正使用ガイド・RMP） |
| 5 | 残っている課題 | 耐性と次の治療、費用・保険の注意点、後発品・バイオシミラー、進行中の試験は？ |
| 6 | まとめ | 年表／各回のポイント／最新の動向（新しい順、日付つき）／目次 |

## 構成表（plan.md）の形
```markdown
# 連載：{title}（{type}）
- 週ID / 準備した日 / ノートブックID / 資料の数
- 主な資料（題名を10件まで）
- 3週の単元（あれば）: 前の週・次の週の題材

## 第1回 <題>
- 範囲: …（この回で話すこと／話さないこと）
- 聞くこと: 1. … 2. … 3. …
- 冒頭の振り返りの問い: （第2回から）
- 次回への橋渡し: …
（第2〜6回も同じ）

## 気になる点
- 資料が薄い回、版の違うガイドラインが混ざっている など
```
