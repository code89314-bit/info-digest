# 週の連載（公開学習アーカイブ）の設計

2026-11-20 に本人と相談して決めた内容。まだ作っていない（コードは未着手）。
毎朝の学習ショート（`src/learn.py`、日曜は復習の回）はそのまま残し、これと並べて動かす。

## ねらい
- 読者は毎日の配信で気になったら、最新の回から遡って読む。テーマがバラバラだと探しにくい。
- 1週間（月〜土の6回）を同じ題材にして、週で共通のタイトルを付ける。最終回（第6回）がまとめと目次。
- 毎日約20分の音声と、note の記事（出典つき。長さは決めない。パイロット版は約9,000字で本人が了承）。
- きっかけ: 学習ショートで同じ話題（ブレンレップの眼毒性）が切り口を変えて続き、アクティブリコールとしてよかった。

## 決まっていること（台本の話者・口調などの詳細は `.claude/skills/series-script/reference/persona.md`）
- 堀田（メイン）は時間を押しがちで誰も止めない。はみ出した分は次の回へ回し、**全6回が全7回になってもよい**（2026-11-20）。
  7回になった週の公開の並び（日曜にも出すか等）は、公開のときに本人と決める。
- どの回にも歴史的な変遷を入れる。第1回の冒頭は疫学（罹患数・死亡数・5年生存率）。
- **日曜に準備（資料の追加・全体の構成）、月〜土に1日1話**（2026-11-20 本人が決定）。NotebookLM のチャットには1日の上限があり
  （しらべの Bot・学習・ニュースと共通）、パイロット版で約30問聞いたところで断られ続けた。1話の質問は6〜8問まで。
  数字や経緯を拾うだけなら `source fulltext`（チャットの回数に数えない）で資料の本文を直接読む。
- ショートと週の連載は並べて動かす。
- 週の連載は毎週作るが、**公開は1週遅れ**。本人が確かめてから、6本まとめて公開する。
- ローカルのモデル（Qwen3.6）には題材も流れも作らせない（薬の名前を取り違えるため）。題材は本人が config で決める。
- **台本は Claude が書く**（2026-11-20）。NotebookLM の音声は専門用語の読み間違い・話者の入れ替わりがあり、
  長く残すアーカイブには品質が足りない。長い台本も NotebookLM では組み立てにくい。
  NotebookLM は「資料を調べて出典つきで答える係」にし、Claude Code のスキル `.claude/skills/series-script` が
  台本（話者3人（メイン・サブ・聞き役）・読みがな付き）・note の記事・事実チェック表を作る。読みがな辞書は `style/series_yomi.yaml`。
- 音声は台本を読み上げソフトで読ませる（ソフトはまだ決めていない）。NotebookLM の音声の枠は使わない。
- 作る時刻は **2:00**（22時台は本人が別のことに使う）。Claude のトークンが足りなければ考え直す。自動化はパイロット版のあと。
- **パイロット版**: EGFR 遺伝子変異陽性 非小細胞肺がん（構造系）。続けて EGFR 阻害薬（クラス追跡）→ タグリッソ（ドキュメンタリー）。

## 3つの切り口（週ごとに替える）
### 1. 構造系（全体を俯瞰する）: がん種ごとの治療・レジメン選択・検査ストラテジー
本人の調べる順（周術期／再発・切除不能 → 1〜3次 → 選ぶ条件とコンパニオン診断）に合わせる。
| 回 | 中身 |
|---|---|
| 1 | 病気の全体像（分類・病期・バイオマーカー）と、治療の歴史の概略 |
| 2 | 検査ストラテジー（いつ何を調べるか、コンパニオン診断、遺伝子パネル検査、保険の条件） |
| 3 | 周術期（術前・術後）の治療と根拠 |
| 4 | 再発・切除不能の1次治療（レジメン選択の根拠となった試験、選ぶ条件） |
| 5 | 2次以降と特別な状況（高齢、PS 不良、臓器障害）、薬剤師の実務と保険の注意点 |
| 6 | まとめ: 治療アルゴリズム1枚、各回のポイント、何月何日時点の最新の動向、目次 |
資料: 専門ノートと同じガイドライン PDF（`.local\guidelines\<キー>\`）＋ 適正使用ガイド ＋ ウェブ調査。

### 2. クラス追跡（比較・歴史のキュレーション）: 薬のクラスを追う
例: 免疫チェックポイント阻害薬、EGFR 阻害薬、二重特異性抗体、トポイソメラーゼ阻害薬、アルキル化薬、ADC、PARP 阻害薬、CDK4/6 阻害薬。
| 回 | 中身 |
|---|---|
| 1 | 作用機序と、クラスが生まれた歴史 |
| 2 | 世代・発売順と根拠の試験（系譜） |
| 3 | 薬どうしの比較（適応、用法、体内動態、相互作用） |
| 4 | クラス共通の副作用と、薬ごとの違い |
| 5 | 使い分け、耐性と次の治療、薬剤師の実務と保険の注意点 |
| 6 | まとめ: 比較表、系譜図、最新の動向、目次 |
資料: 各薬の添付文書・インタビューフォーム・適正使用ガイド・審査報告書 ＋ ガイドライン ＋ 総説。1冊の資料は50件までなので、薬が多いクラスは絞る。
注意: 別々の試験の数値を並べて優劣を言わない（試験間比較）。

### 3. ドキュメンタリー: 1つの薬だけを追う
例: シスプラチン、リツキシマブ、イマチニブ、トラスツズマブ（→ T-DXd）、ペムブロリズマブ、オシメルチニブ。
| 回 | 中身 |
|---|---|
| 1 | 発見と開発の物語（標的の発見、創薬） |
| 2 | 臨床試験の歩み（第I相から承認まで。うまくいかなかった試験も） |
| 3 | 承認と適応拡大の年表（日本と海外） |
| 4 | 現場での使い方（適正使用ガイド、副作用、相互作用） |
| 5 | 残っている課題（耐性、バイオシミラー、費用、保険） |
| 6 | まとめ: 年表、各回のポイント、最新の動向、目次 |
資料: PMDA の審査報告書（開発の経緯の一次資料）・インタビューフォーム・添付文書・主要な論文。
注意: 物語を面白くするための作り話（逸話・発言）を入れない。資料にない話はしない。

### 組み合わせ（3週で1つの単元）
同じ領域を3つの切り口で続けると、アーカイブの中で互いに行き来できる。
例: EGFR 陽性肺がん（構造系）→ EGFR 阻害薬（クラス追跡）→ オシメルチニブ（ドキュメンタリー）。
単元の中では、回の冒頭で関連する週を紹介する。

## 時間割（案）
| 時刻 | 作るもの | 音声 |
|---|---|---|
| 4:00 | 学習ショート（日曜は復習） | 1本 |
| 6:00 | がん薬物療法ニュース | 1本 |
| 8:00〜22:00 | ギモン深堀り・保険の回（水曜） | 0〜2本 |
| 22:30 | 週の連載（月〜土）／日曜はノートブックの準備だけ | 1本 |
- 22:30 に作った分の枠は約5時間後の 3:30 に戻るので、4:00 の学習とぶつからない。ギモン深堀りは 22:00 で諦める。
- 1日の上限5本のうち1本を週の連載用に空けておく（`qa_bot.audio_reserve` に足す）。
- 作れなかった日は、翌日の昼（12:00ごろ）に1回だけやり直す（翌朝は朝の枠とぶつかるため）。
- 夜の通知は「下書きができた」の1行だけ。

## 1晩の処理
1. 日曜の夜: 週のノートブックを作る（資料を入れる。足りなければ止めて知らせる）。ノートブックは1週間消さない。
2. 月〜土の夜: その回の「聞くこと」を NotebookLM に順に聞いて note の本文を作る。
3. 本文をノートブックに入れて音声を作る（今週のテーマ・今日の範囲・前回の振り返り1分・次回の予告。約20分）。
4. note に下書き保存（タイトル「【週のタイトル】第n回 回の名前」、音声と表紙つき）。Discord の note 下書きのチャンネルに知らせる。
5. 1週遅れで、本人が確かめて公開する。シリーズごとに note のマガジンに入れる。第6回の目次に各回のリンクを入れる。

## config の形（案）
```yaml
series:
  enabled: true
  weeks:                      # 上から順に1週ずつ。type: structure（構造系）/ class（クラス追跡）/ drug（ドキュメンタリー）
    - {type: structure, title: EGFR遺伝子変異陽性 非小細胞肺がん, notebook: lung}
    - {type: class, title: EGFR阻害薬, drugs: [イレッサ, タルセバ, ジオトリフ, ビジンプロ, タグリッソ]}
    - {type: drug, title: タグリッソ（オシメルチニブ）}
```
